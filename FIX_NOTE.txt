PLAN:ON final diary/banner/card fix

적용
- 일간 마감 후 스토리 카드 본문은 일간에 펼쳐두지 않음
- 일간은 읽기 전용 '시간별로 한 일 / 하려고 한 일' + 일기 배너
- 하단에는 '오늘 마감 완료 ✓ 카드 보기'만 남겨 카드 모달을 열 수 있음
- 카드 모달에서 이미지 저장 가능
- 카드 표시 항목: 완료 개수 / 총 공부 시간 / 공부 시작 / 공부 끝 / 기상 시각 / 과목별 시간
- '시장/시작/끝/종료' 같은 잘못된 시간별 단독 라벨 필터
- 첨부한 안경+연필 네모 이미지를 일기 배너에 그대로 사용
- 설정 일기장도 동일한 진한 기본색 연동 배너
- 오늘 일기 저장 시 '오늘 쓴 일기 보기' + 미리보기로 변경
- 자정~04:59에 예전 로직으로 저장된 일기도 5시 공부일 기준으로 다시 찾아 표시
- 기존 일기 데이터는 삭제하지 않음
- 설정 > 홈·기록에서 일반 '친구 기능' 그룹 제거 (친구 탭은 유지)
- 마감 후 '기록 고치기' 경로는 차단 상태 유지

SQL
- 이 UI/일기 수정 자체는 새 SQL 불필요
- 친구에게도 카드의 공부 시작/끝/과목별 시간을 보내려면
  RUN_THIS_STORY_CARD_DETAILS_PATCH.sql 을 1회 실행해야 함


PLAN:ON 2026-09-26 마감/일기 수정

- 일간에서 마감 후 스토리 카드/카드 보기 고정 버튼 제거
- 마감 후 원본 기록 수정 경로 차단 (기록 고치기 제거)
- 마감 화면에 큰 네모 일기 CTA 추가
  · 일기 없음: “네모가 일기를 기다리고 있어요 / 일기로 오늘 하루의 마지막을 채워봐요”
  · 일기 있음: “오늘의 일기가 채워졌어요 / 오늘 남긴 마음을 다시 펼쳐봐요”
- 오늘 일기 저장 버그 수정
  · 00:00~04:59에도 5시 기준 오늘 날짜로 저장
  · 신규 일기에 date/studyDate 저장
  · 기존 일기는 달력 날짜 기준으로 다시 찾도록 호환
- 오늘 일기가 있으면 설정/일기장에서 “오늘 일기 보기 ✓ / 오늘 일기 저장됨 ✓” 표시
- 설정 첫 화면의 일반 ‘친구’ 메뉴 제거 (친구 탭은 그대로 유지)
- 시간별 요약의 잘못된 ‘시장/시작’ 단독 표시 제거
- 스토리 카드의 총 공부 시간/시작/끝/기상/과목별 시간 선택 기능 유지
- 내 카드 이미지 저장 기능 유지

SQL
- 이번 수정 자체로 새 SQL은 필요 없음.
- 친구에게 카드 상세(공부 시작/끝, 과목별 시간)를 동기화하려면 기존 RUN_THIS_STORY_CARD_DETAILS_PATCH.sql의 card_details 컬럼이 필요함.
