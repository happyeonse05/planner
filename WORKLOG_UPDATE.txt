할 일 시작/끝 작업시간 기록

- 할 일 행에 시작 버튼 추가
- 시작 후 앱/화면을 닫아도 시작 시각을 todo에 저장
- 끝내기 시 실제 경과 시간을 자동 기록
- 여러 번 시작/끝하면 누적
- 할 일 아래에 작업 51분 / 진행 12분처럼 표시
- 할 일 수정창에서도 오늘/총 작업시간 확인 + 시작/끝내기
- 끝내기와 할 일 완료 체크는 별개
- 완료 체크를 누르면 진행 중 작업기록만 자동 종료한 뒤 기존 완료 처리
- 집중 타이머로 전환하면 단순 작업기록을 먼저 종료하여 중복 집계 방지
- 다른 할 일을 시작하면 이전 진행 중 기록을 종료하고 새 할 일을 시작
- 기존 데이터/백업/동기화는 todo 객체 안에 함께 저장
