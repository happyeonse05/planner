친구 탭
- 상단에 원형 스토리 UI: 내 스토리 + 친구들
- 사진 SNS 기능 없음
- 스토리 종류는 '오늘 마감 카드', '친구와의 약속 카드' 두 종류
- 같은 친구가 24시간 안에 여러 기록을 올리면 원형 배지에 개수 표시 후 넘겨보기
- 오늘 마감 전에는 친구 스토리 잠금 유지

오늘 마감 카드
- 오늘 한 일 선택
- 완료 개수 / 총 공부시간 / 공부 시작 / 공부 끝 / 기상 / 과목별 시간 선택 표시
- 카드 이미지 저장
- 나만 보기로 이미 마감했더라도 카드 내용은 고정한 채 '친구 스토리에 올리기'만 가능

친구 약속 카드
- 연결된 친구와의 약속 시간이 지난 뒤 약속 상세에 '둘의 네모로 남기기'
- 기존 약속의 누구/날짜/시간/장소/무엇 데이터를 자동 사용
- 포즈: 기본 / 카페 / 공부 / 같이 걷기
- 양쪽 네모는 각자의 기본색 사용
- 친구 스토리에서 24시간 노출
- 좋아 / 멋져 / 반짝 반응

네모 상태
- 집중 중: 안경+연필
- 시험 있는 날: 책
- 약속 있는 날: 가방
- 일기 쓴 날: 연필
- 할 일 모두 완료: 쉬는 상태
- 기존 졸림/행복/뿌듯 등 표정도 같이 유지

클릭 상세
- 커플 D-day: 현재 며칠째, 100/200/300일, 1주년, 다음 n00일/주년 날짜
- 고정 강의: 요일/시간/강의번호·장소/적용 기간/시험
- 시험: 과목/종류/날짜/시간/D-day/범위/자료/준비 체크리스트
- 월간: 친구에게 받은 응원 쪽지 n개
