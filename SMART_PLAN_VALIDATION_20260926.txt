DATA SAFETY REVIEW

- restore/load paths call normalize/migrate; schema v8 defaults missing fields without deleting legacy fields.
- save() remains the single normal persistence path (localStorage -> account vault -> IndexedDB backup -> sync scheduling).
- Undo restoration calls the same save() path, so restored local data is queued for normal cloud sync.
- Existing merge/snapshot/deletion guards were left intact.
